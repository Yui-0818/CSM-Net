# MedMamba 实验结果（实验一，路线 A）

在教师提供的三分类医学图像数据上，MedMamba VSSM-tiny 的 DermaMNIST 预训练迁移模型取得 raw test acc 0.6993、宏 F1 0.6277。后续的两阶段续训、Mixup、单周期 20 轮、warmup、标签平滑与 3 折集成都没有超过这个基线；标签平滑按预先定下的规则被 CV 采纳，但增益只出现在一折，不能当作稳定收益。

## 2. 数据与评估协议

数据由任课教师提供，按类别整理为 `ImageFolder`，未做额外清洗：

| 划分 | 总数 | 类 0 | 类 1 | 类 2 |
|---|---:|---:|---:|---:|
| train | 569 | 286 | 210 | 73 |
| test | 143 | 72 | 53 | 18 |

- 原图 RGB 2592×1728；标签文件表头为 `image,lable`（沿用教师文件）。
- 类别不均衡，损失按 fit 集计数取权重；阶段一 fit 集的权重为 `[0.6552, 0.956, 2.3385]`。
- 阶段一：`data/train` 内按 seed 0 随机切 fit 456（232/159/65）/ val 113（54/51/8），val 只用于逐轮选模型。
- CV：`StratifiedKFold(n_splits=3, shuffle=True, random_state=0)`，fit 379/379/380，val 190/190/189。
- test 143 张不参与任何配方选择；各阶段的最终模型在收尾时评估一次，CV 全程不读 test。
- 主指标为宏 F1，同时记录准确率、逐类 F1 与混淆矩阵。
- 阶段一配方：输入 128×128，batch 4，DataLoader workers 0，AdamW（lr 1e-4，weight decay 1e-2）+ 余弦退火，10 轮，类别加权交叉熵；增强为 RandomResizedCrop(0.7–1.0)、水平翻转、ColorJitter(0.2,0.2,0.2)，输入归一化到 [-1,1]。

## 3. 数据审计

用 SHA-256 → dHash ≤ 2 → NCC ≥ 0.99 三级查重，74 个候选里确认 2 对重复：

- 跨集：`test/1/494.jpg` 与 `train/1/552.jpg`，NCC 0.99998；
- 训练集内：`train/1/366.jpg` 与 `train/1/426.jpg`，NCC 0.99995。

其余 72 对候选的 NCC 在 0.42–0.94 之间，逐对核对属于构图相似的不同图像，不是重复。

剔除跨集重复后重训阶段一迁移臂，test acc 0.6993 → 0.7042、宏 F1 0.6277 → 0.6318；阶段二 A 块三个 seed 的准确率与宏 F1 也上升约 0.4–0.6 个百分点。结论不变。主表保留未剔除的结果，剔除后的数字作为敏感性分析单列，不做事后挑选。

## 4. 结果

### 4.1 阶段一：初始化对照

同一划分、同一超参、同一批次顺序，唯一差别是初始化：

| 臂 | val 宏 F1 | test acc | test 宏 F1 | 类 0 / 1 / 2 F1 |
|---|---:|---:|---:|---|
| 迁移（DermaMNIST 权重） | 0.6379 | 0.6993 | **0.6277** | 0.849 / 0.589 / 0.444 |
| 从零 | 0.6188 | 0.6713 | 0.5952 | 0.812 / 0.634 / 0.340 |

迁移相对从零：test acc +0.0280，宏 F1 +0.0325；fit−val 间隙分别为 0.0515 与 0.1614；类 2 F1 为 0.444 对 0.340。逐样本 McNemar 检验中，仅从零答对 9 张、仅迁移答对 13 张，精确二项 p=0.5235，总体准确率的差距并不显著。因此预训练的主要价值在于压缩泛化间隙、改善少数类，而不是把总体精度显著抬高。

### 4.2 阶段二：续训与正则对照

阶段一只有单次运行，配对 bootstrap 只覆盖 143 张测试图的抽样波动，不覆盖训练侧方差（数据顺序、增强、DropPath 轨迹）。因此阶段二把预算改投重复次数与等预算对照，每个块跑 3 个 seed，只换 `--seed`，划分与阶段一完全一致：

- **A_continual**：阶段一末轮权重续训一个 cosine 周期，10 轮，峰值 lr 8e-5；
- **B_mixup**：与 A 等预算、同 seed、同逐 step LR 表、同样本顺序，唯一差异是 Mixup α=0.4；
- **C_single20**：从预训练权重连续训 20 轮，峰值 lr 1e-4，用于区分“分两阶段”与“只是多训 10 轮”；C 的总学习量与 A+阶段一未严格对齐，预注册里已写明。

test 宏 F1 取 3 个 seed 末轮的均值：

| 块 | 设置 | test 宏 F1（三个 seed） |
|---|---|---:|
| A | 阶段一权重续训 10 轮，lr 8e-5 | 0.6213（0.5643 / 0.6604 / 0.6391） |
| B | 同 A，加 Mixup α=0.4 | 0.5981（0.6141 / 0.5994 / 0.5807） |
| C | 预训练权重单周期 20 轮，lr 1e-4 | 0.5551（0.5662 / 0.5326 / 0.5664） |

三块都没有超过阶段一的 0.6277。A 块与阶段一只差 −0.0064，但三个 seed 的极差是 0.0961，训练侧方差与待测效应同量级；B、C 的下降更大。逐 seed 的 McNemar（仅准确率）p 为 0.61 / 0.65 / 1.00；三个 seed 的概率平均模型宏 F1 为 0.6501，但其分层配对 bootstrap 95% CI 为 [−0.0512, +0.0943]，含 0。Mixup 把 fit−val 间隙均值从 0.207 压到 0.163，却没有换到 test 提升，且逐 seed 符号相反；C 块 train_loss 更低，但 test 均值只有 0.5551，比同初值训 10 轮更差。

技术上这一阶段解决了无人值守续跑的等价性：checkpoint 用 `.tmp` + `os.replace` 原子写入并连带保存 AdamW 状态，续跑后 `global_step` 与学习率严格对齐；测试集只在 report 模式读一次。这一组结果说明，在这份数据上继续加续训轮数或 Mixup 没有可靠收益，不能把单次运行的波动当成改进。

### 4.3 交叉验证：配方比较

3 折分层 CV，每折 fit 379 / val 190，其余配方与阶段一相同，全程不读 test：

| 配方 | 末轮 val 宏 F1 | 末 3 轮平均 | best-val |
|---|---:|---:|---:|
| 基线 | 0.5922 ± 0.0364 | 0.5912 ± 0.0201 | 0.6131 ± 0.0223 |
| warmup 2 轮 | 0.5997 ± 0.0641 | 0.5887 ± 0.0471 | 0.6086 ± 0.0539 |
| label smoothing 0.1 | 0.6035 ± 0.0328 | 0.5935 ± 0.0337 | 0.6050 ± 0.0341 |

warmup 的末轮均值略高，但折间方差从 0.036 升到 0.064，末 3 轮反而低 0.0025，按预设规则不采纳。label smoothing 末轮高 0.0113、末 3 轮高 0.0023；逐折看 fold0 从 0.5638 升到 0.6160，fold1 与 fold2 分别低 0.0133 与 0.0049，配对差均值 0.0113、标准差 0.035、t≈0.56，不显著。逐类看，LS 把类 2 的 val F1 从 0.380 提到 0.428，这是它唯一方向一致的收益。预先定下的采纳规则是 Δ末轮 ≥ +0.01 且 Δ末3 ≥ 0，LS 刚好通过，因此 CV 中采用 LS 配方，但不对其显著性作强结论。

### 4.4 3 折集成（对照）

提交口径：MedMamba 提交阶段一迁移 `best.pth`（raw test acc 0.6993、宏 F1 0.6277），3 折 LS 集成只作对照，不作为提交模型。两者宏 F1 差 0.0243，在 143 张 test 上不显著；三折未表现出超过迁移的收益。

把 LS 配方的 3 折模型做 softmax 概率平均，在 test 上评估一次：

| 模型 | test acc | test 宏 F1 | 类 0 / 1 / 2 F1 |
|---|---:|---:|---|
| 阶段一 迁移 | 0.6993 | 0.6277 | 0.849 / 0.589 / 0.444 |
| 阶段一 从零 | 0.6713 | 0.5952 | 0.812 / 0.634 / 0.340 |
| 3 折 LS 集成 | 0.6923 | 0.6034 | 0.838 / 0.594 / 0.378 |

集成模型的混淆矩阵（行=真实）：

```text
[62  9  1]
[12 30 11]
[ 2  9  7]
```

错误集中在类 1 与类 2 的互判。集成模型的宏 F1 比阶段一迁移臂低 0.024，只高于从零臂 0.008；原因是每折模型只用了 2/3 的训练数据（379 张），集成降低的是方差，补不回数据量的损失。按 143 张测试集计算，准确率 0.6923 的 95% 置信区间约为 0.61–0.76，0.024 的差距本身也落在区间内。该结论按原样记录，不做事后挑选。

## 5. 分析与结论

### 5.1 结果归纳

1. 迁移臂的 test 宏 F1 / acc 高于从零臂（0.6277 对 0.5952、0.6993 对 0.6713），fit−val 间隙更小（0.0515 对 0.1614），类 2 F1 更高（0.444 对 0.340）；但 McNemar p=0.5235，总体精度差异不显著，收益主要体现在泛化间隙与少数类。
2. 两阶段续训、Mixup、单周期 20 轮三种改法都没有超过阶段一；A 块的 0.6213 与阶段一 0.6277 的差距落在训练波动范围内。
3. CV 上 warmup 没有收益；label smoothing 的 +0.0113 只出现在一折，按规则采纳，但效果不显著。
4. 3 折集成的 test 宏 F1 比阶段一低 0.024，主要原因是每折训练数据减少，集成没有补回这部分损失。
5. test 只有 143 张，单次宏 F1 的置信区间宽度约 0.1，0.01 量级的差异无法可靠区分。后续对比应增加重复次数，而不是继续微调配方。

### 5.2 分析

第一，训练侧的随机性比预期大。A 块三个 seed 的 test 宏 F1 极差 0.096，而各改动的效应只有 0.01–0.03。用单次划分比较方法，很容易把一次幸运的初始化当成方法收益；这是阶段二改成 3 seed、后续改成 3 折 CV 的直接原因。

第二，测试集 143 张的分辨力有限。单次宏 F1 的置信区间宽度约 0.1，0.01 量级的差异无法可靠区分；McNemar 与 bootstrap 的结果都指向“差异不显著”，与数字表面的高低并不矛盾。

第三，过拟合是这条数据线上更实在的问题。从零臂 fit−val 间隙 0.161，迁移臂 0.051；续训后 A 块的间隙仍有 0.16–0.24，Mixup 能把间隙压到 0.163，却没有换成 test 收益。说明在这批数据上，正则化改善的是训练分布上的拟合程度，不必然转化为测试指标。

第四，小样本下数据量优先于技巧。3 折集成用了 3 个 379 张的模型，仍然输给一个 456 张的单模型；集成的方差收益补不回每折少掉的 1/3 数据。

### 5.3 局限

第一，样本量小：训练池 569 张、测试集 143 张，类 2 只有 73 张（测试 18 张）；按二项分布计算，单次准确率 0.6923 的 95% 置信区间约为 0.61–0.76，宏 F1 又放大了少数类的波动。

第二，重复次数不足：交叉验证只用了 seed 0 的一种折划分，每个配方只训练一次，无法把折间方差与随机种子方差分开；阶段二虽然做了 3 个 seed，但每个 seed 仍是一次运行。

第三，训练预算受限：纯 PyTorch 选择性扫描每轮 21–25 分钟，只能固定跑 10 轮（C 块 20 轮），没有验证更长训练、早停或更大分辨率能否带来收益。

第四，对照不完整：最终集成没有做全量 569 张重训的对照。ConvNeXt-T 已完成 clean 3 折 CV 与最终 test（acc 0.8662、宏 F1 0.7683）；自建 CSM-Net 也已完成（center clean test 0.6649、B 0.6508）。但 MedMamba 使用 raw test，后两者使用 clean test，三模型不能直接按 test 数字排名。ResNet18/50、DenseNet121 等额外网络没有在本条线上补跑。

### 5.4 改进方向

数据与目标层面：对类 2 做过采样或改用 focal loss，在验证集上校准分类先验与阈值，配合测试时增强（TTA）与温度缩放，直接针对类 1 与类 2 的互判。

评估层面：把交叉验证扩到 5 折 × 3 个种子，用配对检验或 bootstrap 置信区间判断改动是否真实有效，并同时报告准确率与宏 F1 的区间，而不是只报点估计。

模型与算力层面：安装官方 CUDA 选择性扫描算子缩短每轮时间，尝试更高的输入分辨率、更大的 batch 与更多轮次；用全量数据重训加多种子集成替代当前的 3 折集成；自建 CNN 的后续重点应放在类 2 与类 1/2 边界，而不是继续堆叠模块。

## 6. 复现说明

本仓库不包含 MedMamba 模型代码，因此不提供可直接运行的训练命令。复现需要：

1. 从上游仓库获取同步基线 `104beb3d641d67cef6f09b94ac299083d91bc417` 的代码；
2. 按 [`../NOTICE`](../NOTICE) 的说明，把 CUDA 融合扫描替换为纯 PyTorch `selective_scan_ref`，并隔离 import-time 演示段；
3. 准备 DermaMNIST 预训练权重与上述 `ImageFolder` 数据；
4. 使用 Python 3.10、torch 2.6.0+cu124、torchvision 0.21.0、timm 0.9.16、einops 0.8.0、numpy 1.26.4、scikit-learn 1.7.2、scipy 1.15.3；
5. 按本文件第 2 节的划分、超参与评估口径复跑。

阶段二与 CV 支持中断续跑：把 `STOP` 文件放到对应产物根目录后，训练在当前轮结束时退出；删除 `STOP` 后重跑同一条命令，会从 `epochs.csv` 记录的位置继续，优化器状态与学习率一起恢复。测试集只在 report 或最终评估时读取。
